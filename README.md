# Monokris Diploma Project — Система заявок с чатом

## Что реализовано
- Публичная форма заявки: ФИО, email, телефон, тема, сообщение, согласие ПДн, CAPTCHA-аналог (арифметическая).
- REST API: создание, просмотр, список, обновление заявок; чат сообщений; аудит; статистика; CSV-экспорт.
- Realtime чат: Server-Sent Events (`/api/sse`) + обычный polling как fallback.
- Админ-панель: логин, листинг, фильтры по статусу, карточка заявки, чат, смена статуса, журнал изменений, статистика, экспорт CSV.
- Безопасность: серверная валидация, JWT auth, RBAC-базовая роль, безопасное хэширование паролей (`scrypt`), ограниченный набор API для публичного доступа.

## Demo script (3–5 минут)
1. На `/index.html` создать заявку.
2. Перейти в `/admin.html`, войти и открыть заявку.
3. Отправить ответ в чате заявки.
4. Открыть ссылку статуса заявителя и показать ответ.
5. Закрыть заявку, показать audit и экспорт CSV.

## Acceptance criteria checklist
- [x] Публичная форма создает заявку и возвращает ссылку статуса.
- [x] Оператор видит заявку, открывает карточку, отвечает в чате.
- [x] Отправитель по public-link видит переписку и пишет снова.
- [x] История сообщений и audit сохраняются.
- [x] CSV экспорт и статистика доступны.
- [x] OpenAPI + ER + sequence приложены.

## Gap-analysis (скелет сайта vs улучшения)
Взято из «скелета» корпоративного сайта:
- лаконичный header + навигация (Главная/Контакты);
- нейтральная палитра и строгие карточки контента.

Добавлено как улучшения:
- система заявок end-to-end;
- чат внутри каждой заявки (SSE);
- админский контур (RBAC, журнал, статистика, экспорт);
- публичный доступ по `public_token` без регистрации.
